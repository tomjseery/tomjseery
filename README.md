### Featured projects

**[Concertable](https://github.com/Concertable)**: live-music booking and payments for venues and artists

Opportunities, applications, signed agreements, messaging and post-show settlement in one workflow.
Five .NET services (B2B, Customer, Search, Auth, Payment) composed with Aspire and talking over gRPC
and Azure Service Bus. Stripe Connect handles settlement, with React web and React Native mobile apps
on Terraform-managed Azure.

`C#` · `.NET 10` · `Aspire` · `EF Core` · `gRPC` · `Service Bus` · `Stripe Connect` · `React` · `Expo` · `Terraform`

<br/>

**[Reunion](https://github.com/tomjseery/Reunion)**: a union-first Result and Option library for .NET

Built around native C# discriminated unions from the ground up, not bolted on. It ships validated
tagged unions on .NET 10 and implements the C# 15 custom-union contract on .NET 11, so the compiler
can check exhaustive matches. Dependency-free and [on NuGet](https://www.nuget.org/packages/Reunion).

`C#` · `.NET 10 / 11` · `NuGet`

<br/>

**[Agent Workboard](https://github.com/tomjseery/agent-workboard)**: a local control plane for Claude Code and Codex CLI sessions

Binds epics, features, work items, Git worktrees and plans to native agent sessions, with
capabilities injected per session rather than installed globally.

`Rust` · `Windows Terminal` · `PowerShell`

<br/>

**[winwrap](https://github.com/tomjseery/winwrap)**: an ergonomic modern C++ layer over Win32

Messages are routed at compile time with `requires` and deducing `this`, with no vtables or macro message maps.
Errors are values via `std::expected`, and native lifetimes are owned through WIL.

`C++23` · `Win32` · `WIL` · `CMake`
